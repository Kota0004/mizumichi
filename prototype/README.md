# プロトタイプ（PoC）

「**地点ごとに冠水閾値を持たせ、雨量で危険度を出す**」という設計が成立するか／伝わるかを確かめるための、
ブラウザだけで動く最小実装です。

## 動かし方

外部ファイル（`data/sample_spots.json`）を読み込むため、**ローカルサーバ経由で開く**必要があります。
`index.html` をダブルクリックで開くとブラウザに阻止されます。

```bash
cd prototype
python3 -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

インターネット接続が必要です（MapLibre GL JS のCDN、地理院タイル）。

## できること

| # | 機能 | 対応する要件 |
|---|------|------------|
| ① | **降水量スライダー**（0〜120 mm/h）。動かすと地点の色が変わる | F-10 |
| ② | 表示する危険度の下限フィルタ、レベル別の件数表示 | F-13 |
| ③ | **現在地アラート**。半径内にレベル2以上の地点が入るとバナー＋音声 | F-20 / F-24 |
| ④ | 気象庁 降水ナウキャストの重ね合わせ（参考・失敗しても本体は動く） | F-03 |
| — | 地点をクリックすると、**閾値と判定理由**が出る | 説明可能性（docs/05-3-2） |

### 位置情報を使わずに試す

`http://localhost` 以外（HTTPSでない環境）ではブラウザが位置情報を拒否します。
その場合は **地図上を Shift＋クリック** すると、その地点を現在地とみなして判定します。

### 見どころ

- 雨量 **50 mm/h** にすると、同じ雨でも
  「サンプル地下道A（自然排水・窪地・過去4回）」＝レベル4 と
  「サンプル高台交差点K（高台・履歴なし）」＝レベル2 に**判定が分かれる**。
  これが「全国一律の閾値では役に立たない」（docs/01-4）ことの実演。
- **0 mm/h でもレベル1が1件残る**（過去の冠水履歴が効いているため）。

## ファイル

```
prototype/
├── index.html               … UI 一式（MapLibre + 地理院タイル）
├── risk.js                  … 危険度判定エンジン（docs/04 の式をそのまま実装）
├── data/sample_spots.json   … ★ダミーの地点データ（実在の危険箇所ではない）
└── README.md                … このファイル
```

`risk.js` はサーバ側（Python）と**同じ式**を使う想定。式を変えるときは `docs/04` も必ず直すこと。
docs/04 の計算例（`T60 = 23.3 mm/h`、50mm/h で `S = 82`）と一致することを確認済み。

## このプロトタイプに入っていないもの（＝MVPでやること）

- 実データ（国交省の冠水注意箇所95箇所、千葉市の地下道13カ所）
- リアルタイム雨量の取り込み（アメダス／ナウキャストの数値化はサーバ側で行う設計）
- バックグラウンドでの接近アラート（OSのジオフェンスが必要。ブラウザでは不可）
- ユーザーからの冠水報告
- オフラインキャッシュ

→ [../docs/06_開発ロードマップ.md](../docs/06_開発ロードマップ.md)

## ⚠️ 注意

**表示している地点はすべてダミーデータです。** 実在の危険箇所を示すものではありません。
実際の通行判断・避難判断には使用しないでください。
