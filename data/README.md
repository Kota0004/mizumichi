# data/ — 取り込んだデータ

このフォルダには、外部から取得した資料をもとに作ったデータを置く。
**リポジトリは公開されているので、置いてよいものと悪いものを区別する。**

## 置いてよいもの

| ファイル | 中身 | 出典・条件 |
|---------|------|-----------|
| `spots_chiba.json` | 危険箇所の座標つきデータ | 国交省「道路冠水注意箇所マップ」の記載事項をもとに、住所を座標へ変換し、OSMのトンネル位置へ寄せたもの。**出典表示が必要**（`attribution` に記録） |
| `spots_chiba.review.csv` | 人手レビュー用の一覧 | 同上 |
| `osm_underpasses.json` | OSMのトンネル・掘割・鉄道橋 | © OpenStreetMap contributors（**ODbL**）。再配布には出典表示が必要。派生データベースを公開する場合は同ライセンスでの提供義務が生じうる |
| `risk_latest.json` | 危険度の計算結果 | 気象庁のデータをもとに算出。**出典表示が必要** |

## 置いてはいけないもの

- **入手した資料そのもの（PDF等）** — 再配布にあたる。二次利用条件が確認できるまで置かない
  （確認事項は [docs/08_自治体連携_打診文案.md](../docs/08_自治体連携_打診文案.md) のB）
- 個人が特定できる情報

`.gitignore` で PDF は除外している。必要なら各自でダウンロードすること
（取得手順は [../はじめかた.md](../はじめかた.md) のステップ2）。

## 注意

`spots_chiba.json` は、`evidence.verified_at` が `null` の地点が**人手で未確認**。
未確認のまま公開・配布しないこと（[docs/07](../docs/07_法務_運用_リスク.md)）。
