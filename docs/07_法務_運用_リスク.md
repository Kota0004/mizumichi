# 07. 法務・運用・リスク

作成日: 2026-08-19

**防災アプリは「間違えたときに人が死にうる」プロダクト**なので、技術より先にここを固める。

---

## 1. 最大のリスク: 誤った安心を与えること

| リスク | 何が起きるか | 対策 |
|-------|------------|------|
| **見逃し（危険なのに安全と表示）** | ドライバーが安心して進入し、水没する | ・**「安全です」と断定しない**。レベル0は「情報なし」と表現する<br>・危険箇所として未登録の場所がありうる旨を常時表示<br>・判定は安全側（再現率優先） |
| **誤報（安全なのに危険と表示）** | 通知が無視されるようになる／不要な迂回で渋滞 | ・ヒステリシス、クールダウン、通知予算（→04-6）<br>・レベル1は通知しない<br>・`reason` を必ず表示して納得感を作る |
| **情報の陳腐化** | 古い情報を最新と誤認 | ・**取得時刻を常に画面に出す**<br>・15分以上古ければ警告バナー |
| **デマ・いたずら投稿** | 誤った通行止め情報が拡散 | ・GPS実測との整合チェック、レート制限、写真推奨<br>・単独投稿ではレベル4にしない（複数一致 or 高信頼ユーザーのみ）<br>・投稿は3時間で自動失効 |

### 表現のルール（UIライティング）

| ダメ | 良い |
|-----|-----|
| 「この道路は安全です」 | 「現時点で冠水の情報はありません」 |
| 「通行止めです」（推定の場合） | 「冠水の報告があります。進入しないでください」 |
| 「水深50cm」 | 「膝が浸かる程度との報告」 |
| 「迂回してください」（断定） | 「迂回を検討してください。最終判断は現地の状況で」 |

## 2. 免責と規約

必ず用意する（アプリ内・ストア掲載の両方）:

- **利用規約**: 本アプリの情報は参考情報であり、通行可否を保証しない。最終判断は利用者が行う。
- **免責事項**: 情報の遅延・欠落・誤りにより生じた損害について責任を負わない。
  ただし**「免責があるから雑でよい」わけではない**。免責は最後の砦であって設計の代替ではない。
- **緊急時の案内**: 危険を感じたら**119番／自治体の情報**を優先するよう明記。公的情報へのリンクを常設。
- **未成年・運転者への注意**: 走行中の操作を禁じる旨を初回起動時に明示。

## 3. 位置情報とプライバシー

| 項目 | 方針 |
|------|------|
| 取得目的 | 接近アラートと投稿位置の記録のみ。**広告・行動分析には使わない**と明記 |
| 処理場所 | **原則として端末内**。サーバに送るのは投稿時の座標のみ |
| 保存 | 移動履歴（軌跡）は保存しない。投稿座標は公開されるため、**自宅前などの投稿は丸め表示**（50mグリッドにスナップ）するオプションを用意 |
| 同意 | 個人情報保護法に基づき、**利用目的を明示して同意を取得**。バックグラウンド位置情報は初回に用途を説明してから要求（iOSは段階的許可が必須） |
| 第三者提供 | 行わない。自治体へ提供する場合は**統計化・匿名化**した形のみ |
| 削除 | 投稿の削除・アカウント削除の導線を必ず用意 |

## 4. 道路交通法（ながら運転）

- 2019年12月施行の改正道交法により、**走行中の携帯電話の使用・画面の注視は罰則対象**。
- したがって設計上:
  - **走行中は画面操作を一切要求しない**（→05-5-3）
  - 通知は**音声を主、表示を従**とする
  - ホルダー固定＋音声のみの利用を推奨する旨を明示
  - 「操作は必ず停車してから」をアプリ内に常設表示
- 将来的に CarPlay / Android Auto に対応させ、車載HMIに寄せるのが本筋。

## 5. データの利用条件（出典表示義務）

| データ | 条件 |
|-------|------|
| 気象庁のJSON・タイル | 気象庁ホームページの利用規約に従う。**出典明示**。公式APIではないため仕様変更リスクを許容する旨を内部で共有 |
| 国土地理院タイル（ベースマップ・標高） | 出典「地理院タイル」の表示。加工した場合はその旨も記載 |
| ハザードマップポータル配信タイル | 出典表示。地理院タイル仕様に準拠 |
| 国土数値情報 | 利用約款に従う（出典明示） |
| OpenStreetMap | **ODbL**。派生データベースを公開する場合は同ライセンスでの提供義務が生じうる。**OSM由来のデータと自前データを分離管理する**。<br>`tools/osm_snap.py` で座標をOSMのトンネルへ寄せているため、`spots` は OSM 由来の情報を含む。`attribution` に出典を記録し、地図画面にも表示すること |
| 自治体の通行規制情報 | 各自治体の利用条件を個別に確認。スクレイピングは**規約とrobots.txtを確認してから**。可能なら正式に連携を打診する |
| 有償配信（XRAIN・河川情報センター） | 契約が必要。再配布条件に注意 |

> **地図画面の隅に出典クレジットを常時表示する**（要件 F-01 の一部として実装する）。

## 6. 自治体・公的機関との関係

- 本アプリは**公的情報を置き換えるものではなく、補完するもの**という位置づけを崩さない。
- 千葉市の地下道冠水情報システムのように、既にセンサーを持つ自治体には**連携を打診**する
  （こちらが表示面を提供し、権威ある情報を載せる形）。
- ユーザー投稿の集計は自治体にとって価値がある（優先確認箇所が分かる）。
  **「データを一方的に取る」のではなく「返す」**関係を作ると持続する。

## 7. アクセシビリティ・包摂性

- 色だけに意味を持たせない（**色＋アイコン形状＋文言**）。
- 音声読み上げ（VoiceOver / TalkBack）対応。
- 文字サイズの端末設定に追従。
- やさしい日本語での表現、将来的に英語・中国語・ベトナム語（在留外国人ドライバー向け）。
