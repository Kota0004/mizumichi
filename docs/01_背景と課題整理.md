# 01. 背景と課題整理

作成日: 2026-08-19 / 作成者: Kota0004

## 1. きっかけとなった事象

2026年8月13日午後から千葉県で記録的な大雨が続き、市街地の道路が広範囲で冠水した。
豪雨から3日後の8月16日時点でも、冠水して動かなくなった**放置車両が2,700台超**道路をふさいだままで、
撤去の見通しが立たず、後続の事故も続発したと報じられている（日本経済新聞・毎日新聞、2026年8月16日）。

この「**冠水していると知らずに車で突っ込む**」という事故は、毎年ほぼ同じ形で繰り返されている。
問題は雨そのものではなく、**「その道が今どうなっているか」がドライバーに届いていないこと**にある。

## 2. なぜドライバーは冠水路に進入してしまうのか

事故報道と既存資料から、進入が起きる要因を4つに整理した。

| # | 要因 | 内容 | アプリで対処できるか |
|---|------|------|-----------------|
| A | **水深が見た目で分からない** | 夜間・濁水・街灯なしでは、路面と水面の境も深さも判別できない。アンダーパスは手前から底が見えない構造。 | △（事前に「ここは深くなる」と教えることは可能） |
| B | **危険量の過小評価** | 「このくらいなら行ける」という誤った自信。実際は水深30cmでも走行不能になりうる（後述）。 | ◎（水深別の危険を数値で提示） |
| C | **情報が事前に届いていない** | 冠水注意箇所マップはPDFで公開されているが、平常時に見る人はほぼいない。豪雨のさなかに探せない。 | ◎（本アプリの中核。現在地連動で自動的に届ける） |
| D | **迂回先が分からない** | 危険と分かっても、代替ルートを知らなければ結局突っ込む／立ち往生する。 | ○（迂回ルート提示。フェーズ2） |

→ **本アプリが主に解くのは C と B、次いで D。**

## 3. 車と水深の関係（危険度設計の根拠）

| 水深の目安 | 車に起きること |
|-----------|--------------|
| 〜10cm | おおむね走行可。ただし水はねで視界が悪化。 |
| 10〜30cm | ブレーキが効きにくくなる。速度が出ていると吸気口から水を吸い、**エンジンが停止する恐れ**。原則として進入すべきでない。 |
| 30cm〜 | 床面を超えて車内浸水。電装品が故障し、パワーウインドウ・スライドドアが動かなくなる。 |
| 60cm〜 | **水圧でドアが開かなくなる**リスクが高まり、車内に閉じ込められる。 |

一般に走行可否の境界は「**ドア下端＝床面が浸からない程度**」とされ、
**乗用車では30cmが実質的な限界**（それ以下でも危険）と考えるのが安全側の設計になる。

> 設計上の含意: アプリのアラートは「通れる／通れない」の二値ではなく、
> **「30cmを超えうるか」を軸にした段階表示**にする（→ [04_危険度判定ロジック.md](04_危険度判定ロジック.md)）。

## 4. 冠水はどのくらいの雨で起きるか

- 市街地の下水道・排水路の計画排水能力はおおむね**時間雨量50mm相当**。これを超えると内水氾濫（下水道が水をさばききれずに起きる浸水）が発生しうる。
- 東京の下水道は「1時間50mm対応」を基本とし、大規模地下街など被害が大きい箇所は「1時間75mm」にレベルアップしている。
- 気象庁は1時間降水量50mm以上・80mm以上を「短時間強雨」として区分している。

ただし実際の冠水は「**その地点の排水能力・地形（窪地／アンダーパス）・直前の累積雨量**」で大きく変わる。
同じ50mm/hでも、平坦な高台では何も起きず、アンダーパスでは車が水没する。

> 設計上の含意: 「降水量○mm以上で危険」という**全国一律の閾値では役に立たない**。
> **地点ごとに閾値を持たせる**（例: この地下道は40mm/h、この道は70mm/h）設計にする。
> これが「降水量でフィルタを掛ける」というアイデアを実装する正しい形になる。

## 5. 既存の情報提供の「穴」

| 既存の仕組み | 良い点 | 穴 |
|------------|-------|----|
| 国交省・各地整の「道路冠水注意箇所マップ」（PDF） | 公的に確定した危険箇所。千葉県内は**95箇所**（2026年6月30日現在、千葉国道事務所） | **PDF・静的**。検索性ゼロ、現在地連動なし、機械可読でない |
| 千葉市 地下道冠水情報システム | 市管理の地下道13カ所の通行可否を**リアルタイム**表示 | 対象が13カ所のみ。市域外はカバーなし。存在を知られていない |
| 気象庁 キキクル（浸水／洪水） | 1kmメッシュ・10分更新で危険度を5段階表示 | **「面」の情報で、道路単位ではない**。「どの道がダメか」は分からない |
| ウェザーニュース 冠水アラーム | ユーザー報告＋解析雨量で1kmメッシュの冠水リスクを通知 | 1kmメッシュ止まり。特定の道路・アンダーパス単位ではない |
| 各県の通行規制情報 | 公式の通行止め | **人が現地確認してから**なので発表が遅い。事故は発表前に起きる |

→ **空いている穴 = 「道路・地点の粒度」×「事前（雨量予測）」×「現在地への自動プッシュ」**。
ここが本アプリのポジション。

## 6. 本アプリが目指すもの（1行）

> **「その道は今、あなたの車で通れるか」を、走り出す前と走行中に、地点の粒度で自動的に知らせる。**

## 7. 対象ユーザー

| ペルソナ | 状況 | 一番欲しいもの |
|---------|------|--------------|
| P1: 通勤ドライバー（30代・千葉市） | 豪雨の夜に帰宅。いつもの道が冠水しているか分からない | 出発前に「今日はこのルート危険」の一言 |
| P2: 土地勘のない運転者（配送・来訪者） | 初めて通る道。アンダーパスの存在自体を知らない | 走行中の**手前でのアラート**（音声） |
| P3: 地域住民・自治会 | 「あそこはいつも溜まる」を知っている | 知っていることを**共有できる場**（投稿） |
| P4: 自治体の道路管理者 | 現地確認の人手が足りない | 住民投稿と雨量から**優先確認箇所**が上がってくる |
