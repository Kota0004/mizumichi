## A. 千葉市 建設局 土木部（地下道冠水情報システム）

**目的**: 13カ所の地下道の通行可否をリアルタイムで受け取れるようにする。
**参考**: <https://www.city.chiba.jp/kensetsu/doboku/dobokukanri/ooame2.html> ／ <https://pub.os-alert.info/chiba/devmap>

### 事前にやること
1. `python3 tools/probe_endpoints.py --url https://pub.os-alert.info/chiba/devmap --browser`
   で、機械可読なデータ取得口があるかを確認する。
2. あった場合も、**規約上使ってよいかは別問題**なので、必ず下記の確認を行う。

### 文案

```
件名: 地下道冠水情報システムのデータ利用について（お問い合わせ）

千葉市 建設局 土木部 ご担当者様

突然のご連絡失礼いたします。
○○大学の（氏名）と申します。

2026年8月の豪雨で、冠水した道路に気づかず進入する車両が多数発生したことを受け、
「冠水しやすい道路を、雨量に応じて事前にドライバーへ知らせる」個人開発のアプリを
検討しております。公的に確定した情報を最優先で表示する設計としており、
貴市の「地下道冠水情報システム」は、まさにその中核となる情報と考えております。

つきましては、以下について教えていただけますでしょうか。

1. 同システムが公開している通行状況データについて、
   個人開発のアプリからの参照（表示・再掲）は可能でしょうか。
   可能な場合、出典表記など満たすべき条件をご教示ください。
2. JSON等の機械可読な形式での提供、またはAPIの公開予定はございますか。
   （現状は画面表示のみと理解しております）
3. 更新間隔と、通信・センサー障害時の値の扱いについて。
4. 将来的に、本アプリに寄せられた住民からの冠水報告を集計し、
   「現地確認の優先度が高い箇所」として貴市へ情報提供することは
   お役に立つ可能性がありますでしょうか。

営利目的ではなく、公開する場合も「最終判断は現地の状況で」「災害時は市および
気象庁の公式情報を優先」と明示いたします。
お忙しいところ恐れ入りますが、ご教示いただけますと幸いです。

（氏名）
（連絡先）
```

## B. 国土交通省 関東地方整備局 千葉国道事務所（道路冠水注意箇所マップ）

**目的**: 千葉県内95箇所（2026年6月30日現在）のPDFデータを、座標付きで利用してよいか確認する。
**参考**: <https://www.ktr.mlit.go.jp/chiba/chiba_index030.html>

### 文案

```
件名: 「道路冠水箇所マップ（千葉県内）」の二次利用について

国土交通省 関東地方整備局 千葉国道事務所 ご担当者様

（前略：Aと同じ趣旨の自己紹介と目的）

貴事務所が公開されている「道路冠水箇所マップ（千葉県内）」について、
以下を教えていただけますでしょうか。

1. 掲載されている冠水注意箇所の位置情報を、地図アプリ上に表示する形での
   二次利用は可能でしょうか。出典表記の方法もご教示ください。
2. PDF以外（CSV・GeoJSON等）の機械可読な形式でのご提供は可能でしょうか。
   PDFから座標に起こす作業には誤りが入る余地があり、可能であれば
   原データを参照させていただきたく存じます。
3. 一覧の更新頻度と、更新をどのように把握すればよいか。
4. 「アンダーパスのうちポンプ設備の有無」の区別はデータとして
   お持ちでしょうか。（排水能力の違いが冠水リスクの判定に直結するため）

（後略：Aと同じ結び）
```

> **質問4は本アプリの精度に直結する。** ポンプの有無で冠水閾値の既定値が
> 35 mm/h と 55 mm/h に分かれる（[04-3-1](04_危険度判定ロジック.md)）ため、
> この1項目が分かるだけで判定の質が大きく変わる。

## C. 千葉県 県土整備部（県管理道路の通行規制情報）

**目的**: 確定情報としての通行止めを取り込めるようにする。
**参考**: <https://www.pref.chiba.lg.jp/cate/baa/lifeline/kendou/index.html>

確認事項:
- 通行規制情報の機械可読な提供（API・CSV）の有無
- スクレイピングの可否（利用規約・robots.txt の該当条項）
- 発表のタイミング（現地確認後か、予防的な事前規制も含むか）

## D. 気象庁（データ利用条件の確認）

気象庁のJSON・タイルは**公式APIとして仕様保証されたものではない**ため、
問い合わせるべきは「使ってよいか」より「**どう使えば規約に沿うか**」。

確認事項:
- 気象庁ホームページの利用規約における、当該データの位置づけと出典表記の方法
- アクセス頻度の目安（5分ごとのタイル取得が過大でないか）
- 仕様変更の告知がどこで行われるか（[気象データ高度利用ポータルサイト](https://www.data.jma.go.jp/developer/index.html) の更新履歴を購読する）
