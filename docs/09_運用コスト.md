# 09. 運用コスト

作成日: 2026-08-22 / 更新: 2026-09-17（全国展開に向けた実測を追記）

**現在の構成は、すべて無料枠に収まる。** ただし条件と落とし穴があるので記録しておく。

---

## いま使っているもの

| サービス | 用途 | 費用 | 条件 |
|---------|------|------|------|
| **GitHub Actions** | 雨量の自動取り込み・テスト | **無料・無制限** | **public リポジトリ**であること（標準ランナー） |
| **GitHub Codespaces** | iPadからの開発 | **無料枠内** | 月 **120コア時間**（2コアで約60時間）＋ 15GBストレージ |
| **GitHub Pages** | アプリの公開（任意） | **無料** | public リポジトリ |
| 気象庁（アメダスJSON） | リアルタイム雨量 | **無料** | 公式APIではない。出典表示。過度なアクセスは避ける |
| 国土地理院（地図・標高・住所検索） | 地図表示、窪地判定、座標化 | **無料** | 出典表示が必要 |
| OpenStreetMap（Overpass API） | 位置の補正 | **無料** | ODbL。コミュニティ運営なので**大量取得しない** |

## ⚠️ 落とし穴4つ

### 1. private にすると Actions が有料枠になる

無料・無制限なのは **public リポジトリ**だから。private に変えると
無料枠は月2,000分になり、毎時実行（月約720回）だけで使い切りかねない。

**private にするなら、`pages.yml` の実行間隔を落とす**こと（例: 6時間ごと）。
なお private では GitHub Pages 自体が有料プラン（Pro 以上）になる点にも注意。

### 2. 60日放置でスケジュール実行が止まる

GitHub は、public リポジトリで**60日間動きがない**とスケジュール実行を自動で無効化する。
防災アプリが気づかないうちに止まっているのは困るので、
`keepalive.yml` が月1回コミットして活動があることにしている。

止まってしまった場合は、Actions のページから手動で再開できる。

### 3. 全国に広げると、毎時コミットが履歴を膨らませる（対処済み）

危険度（`risk_latest.json`）は **1地点あたり約260バイト**（実測）。
これを毎時コミットすると、範囲を広げたときに履歴がこれだけ増える。

| 範囲 | 地点数 | 1回 | 1日(24回) | 1年 |
|------|-------:|----:|----------:|----:|
| 千葉のみ | 89 | 23KB | 0.5MB | 0.2GB |
| 首都圏（1都7県） | 約800 | 203KB | 4.8MB | **1.7GB** |
| 全国 | 約4,000 | 1,016KB | 23.8MB | **8.5GB** |

GitHub の目安はリポジトリ **1GB推奨・5GB で警告**なので、全国に広げると超える。

**対処**: 危険度をコミットするのをやめ、**公開のたびに作って配信する**ようにした
（`pages.yml`）。リポジトリには一切残らないので、地点数が増えても履歴は増えない。
`update-risk.yml` は役目がなくなったので削除した。

副次的に、`GITHUB_TOKEN` の push が次のワークフローを起動しない問題への
`workflow_run` 迂回も不要になり、構成が1本になった。

### 4. 外部サービスへの負荷は「無料だから使い放題」ではない

- **観測点表**（約1MB）は `actions/cache` で持ち回る。毎時取りに行くと月720MBの無駄になる
- **アメダスの観測値**は毎時1回だけ。地点が増えても取得回数は変わらない（1回の観測データを内挿して使うため）
- **Overpass API** はコミュニティ運営。範囲を一括で1回だけ取得し、結果をリポジトリに保存して使い回す
- **地理院タイル**は利用規約に「大量アクセスを避ける」旨がある。標高の取得は1回きりで、結果を `dz` として保存する
