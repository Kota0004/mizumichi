## 中心となるアイデア

既存サービスは「1kmメッシュのリスク」か「センサーのある十数カ所」しかなく、
**その間（道路・地点の粒度で、事前に）が空いている**。

そこで、

```
危険度 = f( その地点の雨量 ÷ その地点の冠水閾値 , 先行降雨 , キキクル , 目撃情報 )
```

という形で、**閾値を地点ごとに持たせる**。閾値は
「種別の既定値（アンダーパスか低地か）× 標高タイルから求めた窪み具合 × 過去の冠水回数」で決め、
使われるほど実績から学習して補正する。

こうすると、ユーザーが求めていた「**降水量でフィルタを掛ける**」は、
式の雨量に任意の値を代入する操作（what-if）としてそのまま実装でき、
**同じ雨量でも地点によって判定が分かれる**という、現実に即した挙動になる。

## ツール（データ整備・取込）

[`tools/`](tools/) に、企画を実データで動かすためのスクリプト一式があります。
すべてネットワーク不要の検証つきです（`./tools/run_tests.sh`）。

| ツール | 役割 |
|-------|------|
| `build_spots.py` | 道路冠水注意箇所の**一覧PDF → 座標つきJSON**＋人手レビュー用CSV |
| `enrich_dem.py` | **標高タイルから相対標高 dz** を求めて冠水閾値を補正 |
| `fetch_amedas.py` | **アメダス10分値 → 各地点の雨量と危険度**（`risk/latest.json` 相当） |
| `review_spots.py` | 座標を**地図上で確認・修正**するレビュー画面（一番手間のかかる作業を短縮） |
| `probe_endpoints.py` | 自治体の公開ページの**データ取得口を調査** |
| `doctor.py` | 環境診断と「**次にやること**」の提示 |
| `risk.py` | 危険度エンジン（サーバ側）。`prototype/risk.js` と**全2,700ケースで一致を検証済** |
| `verify_prototype.js` | プロトタイプの**ブラウザ自動検証13項目** |
| `verify_ipad.js` | iPadの画面サイズ・タッチ操作での検証14項目 |

→ 使い方と実行順は [`tools/README.md`](tools/README.md)

## プロトタイプ

[`prototype/`](prototype/) に、ブラウザだけで動く最小実装があります。

```bash
cd prototype && python3 -m http.server 8000
# → http://localhost:8000/
```

- 降水量スライダーを動かすと、地点の危険度が変わる
- 現在地（または Shift＋クリック）から半径内の危険箇所を検出してアラート
- 地点をクリックすると「この地点の閾値」と「判定理由」が出る

> 実データ（千葉県89箇所）を同梱しています。`prototype/data/spots_chiba.json` が
> 無い場合は、動作確認用のダミーデータにフォールバックします。

## 主な機能（要件定義より抜粋）

### MVP
- 危険箇所マップ（公的な冠水注意箇所＋標高から自動抽出した窪地候補）
- **降水量フィルタ**（what-if モード ／ 現在雨量モード）
- **現在地アラート**（半径300〜500m、走行中は音声）
- 3タップでの冠水報告と地図への即時反映
- オフラインでも地図とアラートが動く

### フェーズ2以降
- 30分先・1時間先の予測モード、進行方向判定による誤報削減
- 危険箇所を避ける迂回ルート提示
- 通勤ルート登録と出発前チェック
- 実績からの閾値学習
- 自治体向けダッシュボード（優先確認箇所の提示）

### 自動で動いている仕組み

| 仕組み | 内容 |
|-------|------|
| `.github/workflows/pages.yml` | 毎時アメダスから雨量を取り込み、危険度を計算して**公開しなおす**（リポジトリにはコミットしない） |
| `.github/workflows/tests.yml` | push のたびに全テストとデータ点検を実行 |
| `.github/workflows/keepalive.yml` | 月1回コミットし、60日放置による自動停止を防ぐ |

**どれも手元での操作は不要**です（スケジュール実行は既定ブランチにマージ後に有効）。

### 残っていること

1. **未確認22件＋要確認6件の位置確認** — `python3 tools/review_spots.py --spots data/spots_chiba.json --ipad`
